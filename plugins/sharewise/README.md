# sharewise für Codex

Dieses Plugin verbindet Codex mit dem Remote-MCP-Server von sharewise:

```text
https://www.sharewise.com/web_mcp
```

## Funktionen

- Wertpapiere inklusive Kurs und Community-Stimmung suchen
- Watchlists anzeigen, anlegen und bearbeiten
- Eigene Einschätzungen veröffentlichen und schließen
- Positionen und Entwicklung von Musterdepots abrufen
- Käufe und Verkäufe in Musterdepots erfassen
- Am Tippspiel „Catch the Monkey“ teilnehmen

## Anmeldung und Berechtigungen

Die Anmeldung erfolgt über OAuth direkt bei sharewise. Das Plugin speichert keine Zugangsdaten. Schreibende Aktionen können öffentliche Einschätzungen, Watchlist-Änderungen oder Transaktionen in Musterdepots auslösen; sie bewegen kein echtes Geld.

Der Zugriff kann in sharewise unter „Verbundene Anwendungen“ widerrufen werden.
